Landing page desenvolvida para a **CS Studio Laser**, clínica de depilação a laser e estética com unidades em Uberlândia e Araxá (MG).

## ✨ Funcionalidades

- Apresentação dos serviços (depilação a laser, tratamentos de beleza e autoestima)
- Seção de diferenciais da clínica
- Formulário de agendamento de horário
- Botão flutuante e links diretos para agendamento via WhatsApp
- Links para as redes sociais da clínica
- Seção com os endereços das unidades

## 🛠️ Tecnologias

- HTML5 / CSS3 / JavaScript
- [Font Awesome](https://fontawesome.com/) para os ícones
- Google Fonts (Poppins)
- [ScrollReveal.js](https://scrollrevealjs.org/) para as animações de rolagem

## ▶️ Como usar

```bash
git clone https://github.com/Gabrielrlp/Studio-Laser.git
```

Depois é só abrir o `index.html` no navegador.
